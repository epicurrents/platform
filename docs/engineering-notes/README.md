# Engineering notes

Long-form developer-facing notes that grew too large for the [ROADMAP](../../ROADMAP.md): active bug investigations with embedded diagnostic findings, planned initiatives with reference material (code snippets, migration tables), and similar deep-dive content.

These differ from the rest of [docs/](../) — which is operator-facing (deployment, operations, troubleshooting) — and from per-app READMEs, which describe stable architecture rather than work-in-progress investigations.

The ROADMAP keeps a short summary + link for each entry here so the planning surface stays scannable; the full content lives in this directory where it can grow without crowding the strategic picture.

Add a file here when a ROADMAP entry's body would otherwise exceed ~50 lines or includes accumulating diagnostic state. Delete the file (or move its conclusions into commit messages / code comments) once the underlying work is shipped.

Notes that had reached that point before the September 2026 history reset stayed in the archive repository named in the [README](../../README.md); where a note here refers to one of them, it says so instead of linking.
