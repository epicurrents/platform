# Server-side scientific computing (compute/). Each carries a next-major cap (as
# cryptography does above): these are floors, not pins, so without one a new
# major lands silently at the next image rebuild — which is how numpy 2.0 and
# pandas 3.0 arrived. The cap makes the next one show up as a reviewable
# Dependabot PR instead.
#
# A project needing packages the platform does not declares them in its own

# scripts/lock-requirements.sh --project. pandas and PyWavelets left here for

# imports both independently of any project.
